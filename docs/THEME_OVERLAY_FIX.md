# 主题切换后图像被遮挡的修复

日期：2026-11-06。

现象：有图像时从夜间切到白天，图像区域变成浅色空白；切回夜间仍为空白。十字线、坐标、OK/NG 及检测结果继续更新。

原因：图像上方有独立的透明叠加窗口，用于绘制十字线和检测状态。该窗口使用 Fuchsia 作为透明色键。原主题过渡遍历所有打开的窗体，把该窗口的背景改成主题背景色，背景不再匹配透明色键，因此变成实色遮罩并盖住 VM 图像。切回夜间时仍不匹配透明色键，所以不会自动恢复。图像文件和算法数据没有因主题切换被删除。

修复：

- 动画主题切换和直接主题应用都跳过使用透明色键的窗口。
- 十字线叠加窗口的绘图背景始终清为透明色键。
- 叠加窗口主动保护背景色，避免其他通用样式入口再次将其改为普通底色。
- 不重载方案，不重新绑定 VM 渲染模块，不更改检测、通信或图像文件。

验证：

1. 修复前独立回归成功复现：一次夜间到白天切换即将叠加窗口背景改成 `#F7F8FA`，而透明色键仍为 Fuchsia，测试按预期失败。
2. 修复后 20 次来回切换通过：叠加窗口背景、未绘制区域像素始终匹配透明色键，窗口句柄不变；普通透明窗口和直接应用主题的入口也通过。
3. 增强真实主窗体回归，在主题切换、VM 并行运行和图像截图阶段检查叠加层透明状态。海康 CircleFind 官方方案的真实加载、渲染、参数页、单次、连续、暂停、继续、停止及退出均通过。
