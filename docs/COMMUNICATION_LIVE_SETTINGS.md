# X Vision 通信与配置即时应用

2026-11-06 更新。主界面右上角新增“通讯”，也可从“设置 → 通讯”进入同一配置页。

## 直接连接下位机

1. 选择 Modbus、串口或 TCP 页，填写设备参数。
2. 点击“应用并连接”。配置会立即保存并应用，后台开始建立连接，不需要先触发检测，也不需要加载 VM 方案。
3. 查看底部状态及收发记录。修改参数后再次点击“应用并连接”；“断开当前通道”会停止该通道的自动重连，其他通道保持工作。

| 通道 | 连接配置 | 调试与结果输出 |
| --- | --- | --- |
| Modbus TCP | PLC IP、端口、站号、超时、自动重连 | 读保持寄存器 FC03、写多个保持寄存器 FC16；沿用检测结果寄存器输出 |
| TCP 主动连接 | 选择“主动连接下位机”，填写下位机 IP/主机名及端口 | 无需触发字符即可双向收发；可单独开启接收触发、ACK 和检测结果发送 |
| TCP 本机监听 | 选择“本机监听”，填写本机监听地址和端口 | 显示“监听中”；有对端连入后显示“已连接”，支持向已连接对端发送 |
| 串口 | COM 名称、波特率、校验位、数据位、停止位、重连参数 | ASCII/HEX 手动发送、原始字节接收显示、可选触发字符与 OK/NG 指令 |

Modbus 地址使用 **0 基址的协议地址**，例如设备文档的 40001 通常对应地址 0，应以设备说明书为准。手动读写使用页面中的站号和起始地址；读取使用配置数量，写入在输入框填写逗号分隔的十进制无符号 16 位数值。单次读取最多 125 个、单次写入最多 123 个寄存器。

TCP/串口发送可选择 ASCII 或 HEX。ASCII 支持 `\r\n` 转义，也可勾选“换行”；HEX 示例 `AA 55 01 02`。收发记录分别标记 RX/TX，并显示文本和十六进制字节。TCP 自动触发仍按换行命令解析，启用触发与建立连接相互独立。ACK 仅表示收到了触发命令，不表示检测已经完成。

勾选 TCP“检测完成后发送结果”后，可配置模板，例如 `{RESULT},{SEQ},{DURATION}\r\n`。服务端模式向当前已连接的客户端发送；没有对端连接时不会虚报发送成功。

## 保存后立即生效

“保存设置”与“应用并连接”均提交配置；输入框里尚未应用的编辑不会直接改变设备。应用时先停止并等待当前检测及结果处理结束，再切换运行参数。统计和已加载方案保留，之后可重新启动检测；无需重启软件。

已处理的运行时引用包括通信通道、检测间隔和异常恢复、判定规则、相机参数及重连配置、预览节流、日志/图片开关、图片格式和归档队列、存储目录、参数预设目录、报表目录/公司/产线信息、自启动及退出选项。

通信仅重建参数发生变化的通道，健康的其他通道不会因保存而断开。相机参数写入失败、路径不可写或配置文件保存失败时会报错；保存失败会尝试恢复此前通信和相机配置，不能将失败显示为成功。设备不在线时可保存有效配置，实际连接失败由状态和日志单独显示。

改变数据目录后，新记录立即写入新目录，原有文件留在原目录；新目录报表读取新目录日志，不会自动搬迁或合并旧历史。归档切换前等待旧队列完成，保存成功后才执行新保留期清理。调试日志采用有界缓存和定时批量显示。

另修复了从未成功加载 VM 方案时，退出却尝试初始化并释放 SDK 单例造成的异常。正常已加载方案仍按原流程释放。
