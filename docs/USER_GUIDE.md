# 操作指南

1. 登录后在“方案管理”添加已在 VM 中验证的 `.sol`，选择并加载。
2. 选择本地图片输入，分别使用“导入单张图片”或“导入整个文件夹”。文件夹导入当前层图片，不递归子目录。
3. 先运行单次检测，检查图像、输出变量、OK/NG 判定来源；再按项目节拍启用连续检测。F1 启动，F3 停止；暂停后可继续。
4. 图像显示下拉框切换流程或模块。缩放、原图比例及十字线仅影响显示；参数页使用 VM 原生参数控件。
5. 右上角日/月图标切换日夜模式。主题自动保存，原生 VM 参数区部分配色沿用 SDK。
6. 在“通讯”中配置 Modbus TCP、TCP 或串口，点击“应用并连接”。连接不依赖加载方案或接收触发。
7. 设置编辑后点击保存才应用；应用会先停止检测，无需重新启动软件。连接失败与配置保存失败分别显示。
8. “检测报告”查询并导出记录；切换数据目录后，新数据写入新目录，原历史保留。
9. 使用工业相机时先枚举、连接、检查曝光和触发模式，再进行目标设备联调。

新方案制作约定见 `samples/README.md`；通讯地址与帧格式见 `COMMUNICATION_LIVE_SETTINGS.md`。没有有效 VM 授权时不能把本地图片导入成功等同于算法运行成功。
